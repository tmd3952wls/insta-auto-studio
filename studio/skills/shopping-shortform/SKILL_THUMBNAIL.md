# 쇼핑 쇼츠 커버(썸네일)

대본 후보마다 커버 제목(thumbnail_text)과 커버 사진(thumbnail_image)을 하나씩 고른다. 커버는 피드에서 손가락을 멈추게 하는 한 장이다. 아래는 사용자 채널에서 실제로 쓴 커버 제목이다. 이 말투와 길이를 따른다(그대로 베끼지 않는다).

```
아이스크림 / 절대 먹지 마세요
다이소 가시면 / 이건 꼭 사오세요
보증금에서 / 50만원을 깐다고요?
올영에서 / 판매 1위한 이거
다이소에서 / 인기투표 1위?
남편이랑 / 여행 갈 때 필수
모든 걸 지워버리는 / 마법의 이거
집에서도 / 암에 걸릴 수 있데
대한민국 천재가 만든 / 역대급 물통
한달에 5KG 뺀 / 다이어트 빵
드디어 사고 친 / 뉴발 역대급 신상
```

커버 제목 규칙:
- 두 줄로 쓴다(줄바꿈 \n). 첫 줄은 짧은 배경(장소·사람·상황: "다이소 가시면", "남편이랑", "보증금에서", "집에서도"), 둘째 줄이 한 방(경고·명령·순위·숫자 결과·반전)이다. 줄마다 공백 포함 5~11자.
- 쓰는 패턴(후보마다 다른 패턴을 고른다):
  - 경고·금지: "절대 ~ 마세요", "~에 걸릴 수 있데"
  - 강한 추천: "이건 꼭 사오세요", "~할 때 필수"
  - 순위·인기: "판매 1위한 이거", "인기투표 1위?" (순위·숫자는 사용자 입력에 있을 때만, 없으면 다른 패턴)
  - 돈·숫자 손해나 결과: "50만원을 깐다고요?", "한달에 5KG 뺀" (숫자는 아라비아 숫자, 사실 근거 규칙을 지킨다)
  - 과장된 찬사: "마법의 이거", "역대급 ~", "천재가 만든", "드디어 사고 친"
- 상품은 "이거"나 넓은 종류 이름("물통", "빵", "신상", "스프레이")으로만 부르고, 상품명·제조사 이름은 쓰지 않는다. 다이소·올영 같은 판매처 이름은 써도 된다.
- 말투는 말하듯이 짧게: "~마세요", "~사오세요", "~깐다고요?", "~있데", "~1위?". 물음표로 끝내면 궁금증이 커진다. 광고 문구("최저가", "지금 구매")는 쓰지 않는다.
- 그 후보의 첫 줄 훅과 같은 방향이되 같은 문장을 그대로 옮기지 않는다.

커버 사진 규칙 (사용자 커버 사진의 공통점):
- 한 가지 대상이 화면을 크게 채운 가까운 장면을 고른다. 멀리서 찍어 작게 보이는 장면은 고르지 않는다.
- 제목과 바로 이어지는 장면을 고른다: 놀라운 질감·상태(녹아내린 아이스크림 덩어리), 닦이는 순간이나 얼룩 같은 문제 상황, 사람이 얼굴 가까이에서 쓰는 모습, 상품 자체가 예쁘게 크게 보이는 모습(물통, 빵, 신발 상자).
- 상품의 모양은 보여도 되지만, 상품명·상표·중국어 글자가 읽히는 장면은 피한다.
- 밝고 선명한 장면을 고른다. 흔들리거나 어둡거나 손·물건에 가려진 장면, 화면 가운데(제목이 들어가는 위쪽~가운데)에 글자가 이미 있는 장면은 피한다.
- 세 후보가 가능하면 서로 다른 사진을 쓴다.
